# gta5rp-admin-helper

Настольное приложение для админов GTA5RP: считает отчёты по скриншотам. Висит в
фоне, по глобальной горячей клавише снимает область экрана, распознаёт текст
через OCR.space и пишет результат в локальную SQLite. Python + PyQt6, только
Windows.

## Что делает

- глобальный хоткей и оверлей для выбора области экрана
- OCR скриншотов через OCR.space API (язык и движок задаются в `.env`)
- учёт отчётов в SQLite, статистика за период (`database/`)
- тёмная тема на PyQt6

## Запуск

```bash
pip install -r requirements.txt

# .env
OCR_API_KEY=ваш_ключ          # бесплатный на ocr.space/ocrapi
OCR_LANGUAGE=rus
OCR_ENGINE=2

python main.py
```

Сборка `.exe`: `build.bat` на Windows, `build.sh` для остальных, подробности в
`docs/INSTALLATION.md`.

## Структура

| Каталог | Назначение |
| --- | --- |
| `app/` | главное окно PyQt6 |
| `ocr/` | процессор распознавания |
| `input/` | глобальный слушатель клавиш |
| `ui/` | оверлей выбора области |
| `database/` | SQLite через `DatabaseManager` |
| `configs/` | настройки |
| `docs/` | ARCHITECTURE, USAGE, FAQ, EXAMPLES, INSTALLATION |

## Ограничения

- Работает только на Windows: PyQt6, глобальные хоткеи, захват экрана.
- OCR внешний: нужен интернет и ключ, у бесплатного тарифа есть лимит запросов.
- Распознавание настроено под конкретные таблицы отчётов GTA5RP, для других
  данных точность будет низкой.
- Тестов нет.
